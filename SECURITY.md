# Security policy

## Supported versions

Until the first stable release, security fixes are applied to the latest code on
the `main` branch only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`shkwon098@gmail.com` with the subject `grasp_synergy_adapter security report`
and include the affected version, impact, reproduction steps, and any known
mitigation.

You should receive an acknowledgement within seven calendar days and an initial
assessment within fourteen calendar days. Please allow time for a fix before
public disclosure. Use the public issue tracker for ordinary defects that do not
have a security impact.
